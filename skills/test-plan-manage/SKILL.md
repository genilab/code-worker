# Manage Test Plan

## Scope

Use this skill when a project or module needs a test matrix or manual-test
script before delivery. It produces normal, integration, regression,
edge-case, and manual coverage plans.
Primary agent role: test-engineer.

## Workflow

1. Read requirements and design.
2. Identify expected behavior, invalid inputs, repeated actions, boundaries, and subsystem failures.
3. Maintain executable and manual test mappings.

## Constraints

- Do not report planned tests as executed results.
