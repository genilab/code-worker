# Record Manual Review

## Scope

Use this skill when a runnable UI, CLI, or API journey needs human-facing
verification. It produces repeatable observations and supporting assets when
useful.
Primary agent role: ui-visual-reviewer.

## Workflow

1. Read the journey's requirements, design, and manual-test steps.
2. Execute and record actual observations, failures, and screenshots when useful.
3. Hand significant findings to the human reviewer or responsible role.

## Constraints

- Do not claim visual acceptance without actual observation.
- Store supporting images only through `asset-manage`.
