# Manage Design Package

## Scope

Use this skill after requirements are complete and before full implementation.
It produces user-flow, module, data/API, UML, validation-rule, and tradeoff
records.
Primary agent role: architect.

## Workflow

1. Read the approved requirements and delivery plan.
2. Propose the design and record decisions and alternatives.
3. Request human design approval before implementation work begins.

## Constraints

- Do not design beyond the approved release scope.
- Do not claim the design matches implementation until verified.
