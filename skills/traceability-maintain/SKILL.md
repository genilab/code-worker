# Maintain Traceability

## Scope

Use this skill when project records need traceability reconciliation. It
produces factual requirement-to-design-to-implementation-to-verification-to-
documentation links.
Primary agent role: orchestrator.

## Workflow

1. Read charter, requirements, design, source references, QA, and documentation.
2. Record complete links and gaps without inference.
3. Route gaps to the responsible role or human reviewer.

## Constraints

- Do not use a link as proof that the linked check passed.
