# Skill Plan — release-review

## Summary

Evaluate release readiness without committing, pushing, tagging, or publishing.

## Description

The workflow checks requirements, design, tests, manual verification, docs,
limitations, hygiene, and explicit human approval.

## Script Requirements

- Reject incomplete or unsupported release claims.
- Produce a factual checklist and delivery summary.

## Delegation to Code

Future deterministic evidence checks may be delegated after requirements exist.
