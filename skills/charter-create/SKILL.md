# Create Charter

## Scope

Use this skill when a project needs its purpose, objectives, users,
requirements, constraints, success criteria, and exclusions recorded. It
produces an approval-ready charter.
Primary agent role: requirements-analyst.

## Workflow

1. Read the plan and collect the charter decisions from the human reviewer.
2. Preserve unresolved choices as questions rather than assumptions.
3. Write the charter and request explicit human approval before downstream work.

## Constraints

- Do not begin design or implementation before charter approval.
- Do not invent scope, success criteria, or exclusions.
