# Skill Plan — documentation-maintain

## Summary

Maintain factual lifecycle documentation, asset references, and INFO navigation
for all records or one selected module.

## Description

The operation reconciles `assets/docs/` and supporting asset references without
manufacturing requirements, QA, or product claims.

## Script Requirements

- Resolve `ALL` or one module before changing records.
- Link only existing, confirmed records and assets.
- Preserve missing evidence as pending or absent.

## Delegation to Code

Future deterministic link checks may be delegated after requirements exist.
