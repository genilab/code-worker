# Documentation Info

## Description

This area contains the maintained control records for Code-worker and the
templates used by initialized delivery projects. All QA records are stored
under `assets/docs/qa/`; navigation uses local INFO documents.

| Entry Point | Location |
| --- | --- |
| Project records | [project/INFO.md](project/INFO.md) |
| Planning records | [plan/INFO.md](plan/INFO.md) |

| Design | [design/INFO.md](design/INFO.md) |

## Public Interfaces

  verified records; it does not create evidence.
