# Roadmap

## Version 0.1.0 — Reusable Template Baseline

Version 0.1.0 scopes the first reusable `code-worker` baseline: the local
development-control documentation, authoritative minimal skill format, core
skills, requirements and QA conventions, and evidence-derived indexes. It
does not include target-product implementation or an automated GitHub release.

## Version 0.2.0 — First Target-Project Application

Version 0.2.0 scopes applying the template to GraphK or another selected target
codebase, defining its modules and requirements, creating any needed
project-specific skills, and producing validated target implementation and QA
evidence without changing the template's local-only control boundary.

## Version 0.3.0 — Operational Maturity

Version 0.3.0 scopes improvements learned from real target-project use,
including narrowly justified workflow automation, stronger release evidence,
and refinements to reusable skills or documentation standards while preserving
the project-plan, requirement, test, and QA traceability chain.
